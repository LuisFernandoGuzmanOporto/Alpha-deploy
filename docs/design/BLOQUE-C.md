# Bloque C — inglés de interfaz

Revisión de `content/en.ts` y del catálogo inglés de `i18n/messages.ts`.
Titular más natural, instrucciones claras para vacíos, errores, globo y pesos,
etiquetas comprensibles y límites planetarios con términos consistentes.
Se conservan las claves y sus parámetros; TypeScript y las pruebas de i18n comprueban la paridad.

No se traducen nombres, países, regiones, notas, fichas ni metodología científica.
Esos textos siguen siendo los datos del equipo; la metodología conserva su aviso de idioma.
No se añaden afirmaciones científicas ni se altera el significado del índice.

Validación: pruebas, build y matriz ES/EN de QA-NOE.md.
